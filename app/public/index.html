pakulist

利用前の確認

決定的な判定だけを、端末内で。

重複投稿を、証拠の形に整理する。

正規に取得したCSVまたはJSONを選択すると、同じ内容または近い内容を異なるアカウントから投稿している候補を検出します。投稿データはこのブラウザの外に送信・保存されません。

利用前の確認

  • 入力するのは、SNSの規約・開発者条件に沿って取得した投稿データだけにしてください。
  • 表示結果は候補です。違反の最終判断と通報は利用者が行ってください。
  • このアプリは自動通報、SNSへの投稿、外部API呼び出しを行いません。
  • 異なるアカウント間の候補を検出するには、比較対象となる複数アカウントの投稿データが必要です。単一アカウントのアーカイブだけでは候補を検出できない場合があります。

01

投稿データを選択

UTF-8のCSVまたはJSONファイルを1つ選択してください。最大5,000件まで処理します。

ファイルは未選択です。

必要な列・キーを確認する

標準CSV/JSONでは id、account、url、postedAt、text が必要です。日時はタイムゾーンを含むISO 8601形式、URLは https:// で始めます。

許可済みのX API v2 Searchレスポンスを保存したJSONは、data と includes.users を含めれば読み込めます。各投稿の id、author_id、created_at、text と、対応するUserの id、username を使って標準形式へ変換します。このアプリはX APIへ接続せず、資格情報も扱いません。

02

判定を設定

完全一致は常に検出します。近似一致は単語トークン集合の重なりで判定します。

UC-03: 起点を指定して後発候補だけを抽出する

起点投稿IDまたは起点アカウントのどちらか一方を指定すると、その投稿より後にある異なるアカウントの一致候補だけを表示します。同時刻の投稿は前後関係を確定できないため除外します。
