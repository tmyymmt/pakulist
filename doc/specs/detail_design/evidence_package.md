# 手動通報向け証拠パッケージ詳細設計

## 1. 目的と範囲

証拠パッケージは、利用者が手動で検出候補を確認し、必要に応じてSNSの通報フォームへ添付・転記するためのローカル出力である。現行MVPはCSVに加え、閲覧・印刷向けのHTML証拠レポートを端末へ保存できる。

レポートは候補の整理を支援するものであり、著作権侵害、規約違反、その他の法的結論ではない。通報の要否・内容・送信は利用者が判断して手動で実施する。本機能は自動通報、外部フォーム送信、X API接続、投稿の取得、データ保存を行わない。

## 2. 最小証拠セット

| 項目 | HTMLレポート | CSV | 目的 |
| --- | --- | --- | --- |
| 生成日時 | 必須 | CSVファイル作成時刻は含めない | 出力の作成時点を確認する。 |
| 判定設定 | 必須 | 出力種別・類似度列で補完 | 近似一致、閾値、URL／メンション除外の再現性を確保する。 |
| 判定種別・類似度 | 必須 | 必須 | 完全一致または近似一致の根拠を確認する。 |
| アカウント・投稿URL・日時・本文 | 必須 | 必須 | 利用者が投稿を手動確認するための最小証拠。 |
| 起点・後発候補・時刻差 | UC-03時に必須 | UC-03時に必須 | 時系列コピー候補の前後関係を確認する。 |
| 候補・手動確認の注意 | 必須 | HTMLレポートで明記 | 自動的・法的な結論と誤認しないようにする。 |

HTMLレポートは通常の重複投稿クラスタとUC-03の後発コピー候補の双方を扱う。レポートに埋め込む利用者入力はHTMLエスケープし、本文を実行可能なマークアップとして扱わない。投稿URLはHTTPS形式の検証済みURLだけをリンクとして出力し、`noopener noreferrer`を付ける。

## 3. 出力形式

| 形式 | ファイル名 | 用途 |
| --- | --- | --- |
| CSV | `pakulist-results.csv` または `pakulist-copy-candidates.csv` | 表計算・再集計・転記。 |
| HTML | `pakulist-evidence-report.html` | ブラウザでの手動確認、印刷、PDF化する場合の利用者操作。 |

PDFはブラウザの印刷機能を利用者が明示的に選ぶ場合だけ作成する。アプリはPDF生成・外部送信を自動化しない。

## 4. スクリーンショットの扱い

現行MVPはスクリーンショットを取得・保存・送信しない。必要な場合、利用者が対象投稿をブラウザで確認し、SNSの規約、開発者条件、投稿者・第三者の権利、組織の保存方針を確認した上で手動取得・添付する。

| 項目 | 方針 |
| --- | --- |
| 取得主体 | 利用者または利用者が権限を与えた担当者。 |
| 保存先 | 利用者が管理する保存先。現行MVPは保持しない。 |
| 取得許可・規約 | 利用者が確認する。自動取得や回避手段は実装しない。 |
| レポートとの関係 | HTMLレポートは投稿URLと日時を残し、必要に応じた手動スクリーンショットとの照合を支援する。 |

## 5. 確認手順

1. 検出結果を画面で確認し、候補であることを理解する。
2. 必要なら「証拠レポートを保存」を選び、端末内のHTMLレポートを確認・印刷する。
3. 投稿URLを利用者が明示的に開き、投稿の現状とURLを手動確認する。
4. 必要なスクリーンショットは、規約と権限を確認して利用者が手動で取得する。
5. 利用者が通報の要否を判断し、SNSの通報フォームを手動操作する。

## 6. テスト

単体テストは通常クラスタとUC-03候補について、生成日時、判定設定、時刻差、注意文、HTMLエスケープを検証する。E2Eはレポートのダウンロード、ファイル名、注意文、HTMLエスケープを検証する。
