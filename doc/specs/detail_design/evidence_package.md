# 手動確認・通報向けHTML証拠パッケージ 詳細設計

## 1. 目的と適用範囲

本書は、現行のローカルWebアプリが検出結果を利用者端末へHTMLとして保存する**証拠パッケージ**の仕様を定義する。出力は候補の確認・共有・印刷準備を支援するものであり、違反、侵害、アカウント間の関係性その他の結論を自動で出すものではない。

現行MVPでは、利用者が選択したローカルCSV/JSONをブラウザ内で処理し、HTMLを利用者端末へ明示的に保存する。意味的類似判定を有効にした場合だけ、選定候補の本文はローカル意味的APIを経由してOrcaRouterへ送信されるが、証拠パッケージの生成・保存自体はブラウザ内で行う。サーバーへのファイルアップロード、スクリーンショット取得、通報フォームの送信、自動遷移は行わない。

## 2. 出力条件とファイル

| 項目 | 仕様 |
| --- | --- |
| 有効条件 | 通常のクラスタ又はUC-03の後発コピー候補が1件以上あること。 |
| 操作 | 利用者が「証拠パッケージを保存」を明示的に選択する。 |
| ファイル名 | `pakulist-evidence-package.html` |
| 文字コード | UTF-8 |
| 生成場所 | ブラウザのメモリ内。Blob URLを用いて利用者端末へ保存する。 |
| 外部リソース | 読み込まない。スタイルは文書内へ埋め込む。 |

候補が0件の場合は保存操作を無効化する。入力や設定が変わった場合、利用者が再解析するまで前回結果の保存操作を無効化する。

## 3. 出力内容

HTMLには生成日時、利用上の注意、判定設定、検出結果を含める。本文・URL・アカウントを含む出力は、**利用者が正規に取得し、保存・共有する権限を確認したローカル入力**だけを対象とする。将来のAPI取得X Contentを同じ出力へ含める場合は、`external_data_governance.md`の再配布・表示要件を満たし、データソース別の制約をメタデータで区別してから別途有効化する。

| セクション | 内容 |
| --- | --- |
| ヘッダー | パッケージ名、生成日時。 |
| 利用前の確認 | 候補であること、最終確認は利用者が行うこと、自動通報を行わないこと。 |
| スクリーンショットの扱い | アプリは取得・保存しないこと、必要時は利用者が公開範囲・許諾・規約を確認して最小限を自身の端末で扱うこと。 |
| 判定設定 | 解析モード、近似一致の有無・閾値、URL/メンション除外、意味的類似の有効状態、起点指定（ある場合）。 |
| 意味的確認集計 | 完了件数、`match`件数、棄権・利用不可件数、LLMによる近似一致の追加件数、文字列近似候補の除外件数。 |
| 通常クラスタ | クラスタID、判定種別、最大類似度、アカウント数、投稿数、各証拠投稿のアカウント・日時・URL・本文。近似一致では意味的確認の完了件数、ラベル集計、最大スコア、解決済みモデルを含める。 |
| UC-03候補 | 候補番号、判定種別、類似度、起点からの時刻差、起点投稿と後発候補のアカウント・日時・URL・本文。 |

投稿URLは`target="_blank"`と`rel="noopener noreferrer"`を持つ利用者向けの参照リンクとして出力する。リンクを保存時又は生成時に開いてはならない。

## 4. 安全要件

| ID | 要件 |
| --- | --- |
| EV-01 | アカウント、本文、URL、日時、設定その他の入力由来値をHTMLとして解釈せず、文字列としてエスケープする。 |
| EV-02 | 外部スクリプト、外部スタイル、外部画像、フォーム送信を許可しないContent Security Policyを付与する。 |
| EV-03 | 本文は改行を保ちながら折り返し表示し、HTML要素を挿入しない。 |
| EV-04 | スクリーンショット、資格情報、APIトークン、ブラウザストレージの情報を取得・保存・出力しない。意味的確認の集計は保存できるが、APIキー、完全なプロンプト、上流応答本文は保存しない。 |
| EV-05 | 出力に「候補」であること、最終判断を利用者が行うこと、自動通報をしないことを明記する。 |

## 5. 検証

`app/test/evidence.test.js`は、CSP、注意事項、スクリーンショット非自動化の記載、HTMLエスケープ、通常クラスタとUC-03候補の出力、判定設定、意味的確認集計、入力検証を確認する。ブラウザE2Eでは、結果がある場合だけ証拠パッケージ保存を有効化し、結果0件又は設定変更後には無効化することを確認する。

将来の外部データ連携では、データソース別の出力可否、削除・保護化への追従、再配布制約、権限確認を統合テストへ追加するまで、API取得Contentを証拠パッケージの対象に含めない。
