# 価格設計・マネタイズ方針

## 1. 二層構造

本プロジェクトは「OSS のベース部分」と「クローズドな有料サービス」の二層で構成する。

| 層 | 公開範囲 | ライセンス | 提供価格 | 役割 |
| --- | --- | --- | --- | --- |
| ベース部分 | GitHub で公開 | Apache License 2.0 | 無償 | 同一投稿の検出・リスト化。単体で完結して動作する |
| 有料サービス | 非公開（クローズド） | 独自ライセンス（TBD） | 有償（TBD） | AI による類似投稿判定など、ベース部分を前提とした追加機能 |

## 2. 有料機能の境界

- **無償で提供する**: 完全一致・近似一致など、LLM を使わない決定的な判定
- **有料で提供する**: AI（LLM）による意味的な類似投稿判定
  - 言い換え・表記揺れ・部分改変を伴うパクツイの検出がここに該当する
- 判定境界の理由: LLM 呼び出しに変動コストが発生するため、コストが発生する機能を課金対象とする

## 3. LLM 利用の前提

- AI 判定の LLM 呼び出しは **OrcaRouter** を経由する
- 利用者が自前の API キーを持ち込む方式（BYOK）を許容するかは TBD
- LLM コストの単価・想定利用量・原価計算は TBD（`doc/specs/measurement/` の KPI 定義と合わせて詰める）
