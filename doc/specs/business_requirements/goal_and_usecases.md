# ビジネス要件（ゴール・目的・ユースケース）

本ファイルは、本プロジェクト（pakulist）が「何のために」「誰の課題を」解決するのかを定義する。
技術的な実現方法は `doc/specs/system_requirements/system_requirements.md` に記載する。

## 1. ゴール

- SNS上で同一（または実質同一）の投稿をしている複数アカウントを検出し、リスト化する
- 今後の拡張として、検出したアカウント間の関係性を可視化する（グラフ表示等）
  - 本バージョンではスコープ外。将来拡張として位置づける

## 2. 目的

- SNS上で同じ投稿をしているアカウント群を、SNS運営へ通報できる状態にすること
  - 「検出」だけでは価値が完結しない。通報に必要な証拠（投稿URL・スクリーンショット等）が揃うことをゴールに含める
  - 通報の最終判断・実行は利用者が行う（本システムは自動通報を行わない。詳細は要件側で定義）

## 3. ユースケース

| ID | ユースケース | 想定利用者 | 概要 |
| --- | --- | --- | --- |
| UC-01 | 競合他社の過剰なボット投稿を通報する | 企業のマーケティング/法務担当 | 同一文面を大量投稿するアカウント群を検出し、証拠を添えて通報する |
| UC-02 | 同じ投稿をしている複数アカウントを通報する | 一般利用者・企業 | 複数アカウントによる重複投稿（スパム的挙動）を検出して通報する |
| UC-03 | パクツイを検知して通報する | オリジナル投稿の作者 | 自分の投稿が無断でコピーされている投稿を検出し、通報する |

### 3.1 ユースケースの前提

- UC-01/UC-02 は「同一文面が複数アカウントから投稿されている」ことを検出対象とする
- UC-03 は「1つのオリジナル投稿に対して、後から類似投稿が存在する」ことを検出対象とする
  - オリジナル判定は投稿時刻の前後関係を基本とする（詳細な判定仕様は詳細設計で定義）

## 4. 提供形態（ビジネスモデルの概要）

- ベース部分: OSS として GitHub で公開（無償）
- 有料サービス: ベース部分を前提とした追加機能（クローズドソース）
- 詳細は `doc/specs/pricing/monetization_policy.md` を参照
