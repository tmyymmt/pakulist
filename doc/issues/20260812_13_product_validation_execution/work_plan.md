# Issue #33: プロダクト検証計画を実施し、価格・優先順位を確定する 作業計画

## 目的

利用者、価格、無料/有料境界、AI・外部データ取得・関係性グラフ・既存OSS改善の次の優先順位を、同意済みの利用者検証に基づいて決める。

## 実施範囲

| 区分 | 実施内容 |
| --- | --- |
| 対象者 | ブランド保護・マーケティング運用担当、法務・コンプライアンス担当、オリジナル投稿者を対象に、探索的インタビューとタスク観察を行う。 |
| デモ | 架空又は権利・利用許諾を確認済みのデータだけを用い、現行MVPの検出、UC-03候補、CSV・HTML証拠出力を操作してもらう。 |
| 計測 | 初回価値到達、証拠整理、タスク時間、候補理解、AI未充足、継続利用意向を匿名の集計値として記録する。 |
| 価格・優先順位 | 代替手段、導入条件、利用量、承認者、導入障壁を聞き、実装のGo/No-goを決定する。 |

## 非対象

参加者名、所属、連絡先、投稿本文、URL、アカウント、ファイル名、IPアドレス、録音、生の自由記述をリポジトリへ保存しない。外部Xデータ取得、課金開始、AI APIの有効化、自動通報も対象外とする。

## 完了条件

1. `product_validation_plan.md`の成功基準に対する匿名集計を作成する。
2. 仮説ごとの採否、未解決事項、次の優先順位を`product_validation_results.md`に記録する。
3. 価格は承諾額だけで判断せず、価値・導入条件・利用量・代替手段を根拠に扱う。
4. AI、外部データ取得、関係性グラフ、OSS改善の実装又は保留を明示する。
