# Issue #42: AI HACK 2026向けpakulistのQiita紹介記事を作成する 作業計画

## 目的

AI HACK 2026でのpakulist開発活動について、課題、最小プロトタイプ、品質確認、AI連携の安全境界、今後の展開を説明するQiita投稿用Markdownを`doc/qiita/`へ追加する。

## 記載範囲

| 項目 | 方針 |
| --- | --- |
| 投稿メタデータ | Qiitaで使うタイトルとタグ候補を記事冒頭へ明示する。 |
| ハッカソン | AI HACK 2026の公式サイトを出典として、イベントの文脈と開発活動を紹介する。 |
| プロダクト | GitHubリポジトリ、ローカルMVP、決定的検出、時系列候補、CSV・HTML出力、品質確認を事実に基づいて説明する。 |
| AI連携 | OrcaRouter日本語サイトへリンクし、現行MVPはAI APIを呼ばず、最小サーバーAPIは本番有効化前の試作であることを明記する。 |
| 表現 | 候補と最終判断を分け、違反・侵害・アカウント関係を自動で断定しない。実データ、資格情報、個人情報は記載しない。 |

## 非対象

Qiitaへの実投稿、実投稿データ又はAPIキーの掲載、現在のMVPに対する機能変更、実AI精度・原価の未実施検証を完了済みと扱うことは対象外とする。

## 完了条件

1. `doc/qiita/`に単体で投稿可能なMarkdownを置く。
2. 指定されたハッカソン、pakulist、OrcaRouter、参考掲載ページへのリンクを含める。
3. タイトル・タグ候補、プロダクトの現在地、今後の展開、参考資料を含める。
4. 文書の差分検査を通過する。
