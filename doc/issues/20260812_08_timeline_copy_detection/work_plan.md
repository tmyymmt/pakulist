# Issue #4: 時系列を考慮したコピー候補検知

## 目的

UC-03の「1つのオリジナル投稿に対して後から類似投稿が存在する」条件を、正規に取得済みのローカル入力データだけで判定する。起点投稿IDまたは起点アカウントを利用者が指定し、起点より後に投稿された異なるアカウントの完全一致・近似一致だけを候補として表示・CSV出力する。

## 実装範囲

| 領域 | 対応内容 |
|---|---|
| 検出ロジック | `findLaterCopyCandidates`で起点指定、異アカウント条件、厳密な時刻順、完全一致・近似一致を判定する。 |
| 時刻の扱い | 起点より前の投稿と同時刻の投稿は後発判定できないため除外する。入力日時は既存のタイムゾーン付きISO 8601検証を前提とする。 |
| 表示 | 起点投稿、後発候補、判定種別、類似度、起点からの時刻差を表示する。 |
| CSV | 起点・候補双方と`timeDifferenceSeconds`を`pakulist-copy-candidates.csv`へ出力する。 |
| 安全性 | 結果は時刻順と本文類似による候補であり、著作権侵害その他の法的結論ではないと明記する。外部API、認証、保存、自動通報は追加しない。 |

## 検証

単体テストでは、起点より前の投稿、同時刻の投稿、同一アカウント投稿を除外し、後発の完全一致・近似一致だけを抽出すること、起点アカウント指定、入力エラー、CSVの時刻差と数式無害化を確認する。E2Eテストでは、起点投稿を入力して結果表示・時刻差・専用CSV保存を確認する。
