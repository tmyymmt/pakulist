# Issue #7: 関係性グラフのデータモデルと保持境界

## 設計成果

`relationship_graph_data_model.md`に、事案、入力集合、アカウント、投稿、検出実行、クラスタ、時系列コピー候補、アカウント間エッジ、エッジ根拠の論理スキーマを定義した。グラフのノードはアカウント、エッジは決定的な本文一致・近似一致・後発コピー候補の集計だけを表す。エッジは人物関係、違反、侵害を判定・示唆するものではない。

## 保持境界

| 区分 | 方針 |
| --- | --- |
| 現行MVP | ブラウザ内・無保存を維持し、モデルは設計契約だけに留める。 |
| 明示的なローカル出力 | 利用者の端末にだけ保存される。出所と利用制約を表示し、利用者が管理する。 |
| 将来のAPI取得Content | 承認・認証・削除運用・保持上限・アクセス制御を実装した後にだけ扱う。 |
| 導出データ | 本文を含めない根拠・集計を中心にし、元Contentの削除時にはエッジを再集計または削除する。 |

## API契約

本文を含まない`nodes`と`edges`、期間・種別・最小根拠件数の`filters`、ページングを含むJSON Schemaと応答例を追加した。契約例は、自己ループ禁止、ノード参照整合性、時系列整合性、根拠件数の制約をテストで確認する。

## 対象外

データベース、認証、外部API、投稿本文のサーバー保存、グラフUI、AI/LLM、通報操作の自動化は本Issueで追加しない。これらは外部データガバナンスのゲートを満たす後続フェーズで扱う。
