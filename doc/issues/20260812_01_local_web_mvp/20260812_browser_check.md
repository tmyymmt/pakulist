## 結論

主要なMVPフロー（ローカルファイル読込、決定的な完全一致検出、証拠表示、CSV出力）がブラウザ上で確認できた。サンプルの近似一致は既定閾値0.80未満のため表示されず、設定を下げた場合に候補化される設計である。

## 近似一致の確認

閾値を0.65に変更してサンプルを再解析したところ、完全一致クラスタ1件に加えて、`市場 ニュース 速報` と `市場 ニュース 更新` の近似一致クラスタ1件を表示した。近似一致クラスタは最大類似度0.67、アカウント2件、投稿2件として表示され、既定閾値0.80では候補化されないことも確認済みである。
