# Issue #35 引継ぎ記録

**記録時刻:** 2026-08-12 17:15 JST
**対象Issue:** #35「X API取得の利用枠・従量課金を設計する」

## 今回の決定

有償版は、必要な承認・ガバナンスを満たしたX APIのオンデマンド取得を提供できる。ただし、X APIの高コスト又は契約変更リスクを利用者又は運営者が無制限に負担しないよう、提供方式は従量課金又は定額利用枠だけとする。取得前に見積り、明示承認、サーバー側予約を必須とし、80%警告、100%停止、原価・契約上限、429、料金カタログ期限切れ、契約不整合で次の呼び出しを開始しない。

## 現行MVPへの影響

現行OSS MVPには外部X API、APIキー、認証、決済、利用枠、サーバー保存を追加しない。ローカルCSV/JSONをブラウザ内で解析する既存動作は変えない。

## 未解決の外部依存

Xの書面許可・Developer Policy・課金契約・エンドポイント・単価・請求単位、販売単位と販売価格、税・決済・返金・会計の責任者、サーバー側シークレット、利用者認証、事案別権限、削除・監査・障害対応は未確定である。APIキー、契約の機密値、X Content、決済情報をリポジトリ、Issue、PR、ログへ保存しない。

3. 有効な料金カタログと決済・税・返金の責任分界が承認された場合だけ、認証済みサーバー側に見積り・予約・消費・精算・監査を実装する。
4. 実測が利用枠・原価・利用者価値の基準を満たさない場合は、有償X API取得を販売・有効化しない。
