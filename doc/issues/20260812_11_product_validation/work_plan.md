# Issue #12: プロダクト検証設計

価格・AI・取得・グラフの実装は、検証結果と外部データガバナンスのゲートを満たすまで先取りしない。特に#8は、意味的類似への具体的な未充足と原価上限を確認できた場合だけ限定実験へ進める。
