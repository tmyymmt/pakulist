# Issue #4 作業計画: UC-03向け時系列コピー候補検知

## 1. 目的

起点アカウントを指定し、その最も早い一致投稿より後に出た他アカウントの完全一致・近似一致投稿だけを、コピー候補として抽出・証拠表示・CSV出力できるようにする。

## 2. 対象範囲

| 区分 | 内容 |
| --- | --- |
| 入力 | 任意の`originAccount`を追加し、空欄では従来どおりの対称的な重複検出を行う。 |
| 時系列 | 起点アカウントの最も早い一致投稿を起点とし、厳密に後の投稿だけを候補にする。同時刻・先行投稿は除外する。 |
| 近似一致 | 起点投稿と候補を直接Jaccard比較し、設定閾値以上だけを残す。 |
| 出力 | 起点・候補の役割、起点ID、後発候補件数、秒差を画面・CSVへ表示する。 |
| 注意 | 候補抽出は法的結論でないことを画面へ明示する。 |
| 非対象 | X API、資格情報、外部取得、保存、AI意味類似、スクリーンショット、自動通報、法的判断。 |

## 3. 競合回避

担当は `tmyymmt`、作業ブランチは `issue/20260812_08_copy-candidate-timeline` とする。変更対象は検出オプション、時系列フィルタ、CSV、設定画面、単体・E2Eテスト、仕様、README、本Issue専用の作業記録に限定する。外部連携・データモデル・証拠パッケージ・関係性グラフは別Issueに残す。

## 4. 受入条件

- [ ] 起点投稿または起点アカウントを指定する入力モデルがある。
- [ ] 同時刻・日時欠損・時差の扱いが明文化されている。
- [ ] 後発投稿だけを候補にし、起点・候補の時刻差を画面・CSVに出力する。
- [ ] 完全一致・近似一致・先行／同時刻除外の回帰テストがある。
- [ ] 候補抽出が法的結論でないことをUIに明示する。
