# Issue #5 作業計画: 手動通報向け証拠パッケージの要件と出力

## 1. 目的

既存のCSV出力に加え、利用者が手動確認・印刷に使えるHTML証拠レポートをローカルへ保存できるようにする。レポートは候補である旨、生成日時、判定設定、投稿証拠、UC-03の起点・後発候補・時刻差を含む。

## 2. 対象範囲

| 区分 | 内容 |
| --- | --- |
| HTMLレポート | 通常クラスタとUC-03後発候補を、候補注意・設定・投稿URL・日時・本文とともに出力する。 |
| 安全性 | 利用者入力をHTMLエスケープし、リンクを`noopener noreferrer`で出力する。 |
| 手動確認 | ブラウザでの表示・印刷は利用者の明示操作で行う。PDF化はブラウザ印刷を利用者が選ぶ場合だけとする。 |
| スクリーンショット | 自動取得・保存・送信は実装しない。利用者の手動取得と規約・許可確認を前提にする。 |
| 非対象 | 自動通報、通報フォーム送信、外部データ取得、X API、認証、保存、スクリーンショット自動化、法的判断。 |

## 3. 競合回避

担当は `tmyymmt`、作業ブランチは `issue/20260812_09_evidence-package` とする。変更範囲はHTMLレポート生成、保存ボタン、単体・E2Eテスト、仕様、README、本Issue専用の作業記録に限定する。UC-03の検知自体は先行PR #24で実装済みのため変更しない。関係性グラフ、AI、永続データは別Issueに残す。

## 4. 受入条件

- [ ] URL、投稿本文、日時、アカウント、判定設定、生成日時を含む最小証拠セットを定義する。
- [ ] スクリーンショットの取得主体、保存先、許可、規約準拠を明文化し、自動取得を実装しない。
- [ ] CSVに加え、閲覧・印刷用HTMLレポートを出力する。
- [ ] 出力物に候補判定・最終確認・手動通報の注意を記載する。
- [ ] HTMLエスケープ、通常クラスタ、UC-03候補、ブラウザダウンロードをテストする。
