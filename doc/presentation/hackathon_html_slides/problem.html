サービスと成果物の概要

[ SERVICE ]
pakulistは、重複・後発類似投稿を
人が判断できる証拠へ整理する
ローカル検証サービスです。
候補を見つけるだけでなく、投稿URL・時刻・本文・判定根拠を揃え、確認者が次の対応を判断できる状態を作ります。
[ WEB MVP ]
ブラウザ内で安全に処理
正規に用意したCSV / JSONをローカルで扱う。
[ DETECTION ]
候補を決定的に整理
完全一致・近似一致・時系列候補を提示する。
[ EVIDENCE ]
根拠を出力
URL・時刻・本文をCSV / HTMLで確認可能にする。
[ BOUNDARY ] 最終判断は人に残す。 外部API・サーバー保存・自動通報は行わない。
