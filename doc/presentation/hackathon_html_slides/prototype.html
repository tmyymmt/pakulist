最小プロトタイプで判断の流れを実証

必要な部分だけを実装し、候補を人の確認へ安全に渡す流れを検証した。
[ INPUT ]
ローカル入力
正規に用意した
CSV / JSON
→
[ DETECT ]
決定的検出
完全一致・近似一致
時系列候補
→
[ EVIDENCE ]
根拠を出力
URL・時刻・本文
CSV / HTML
→
[ REVIEW ]
人が判断
候補を確認し
次の対応を決める

[ VERIFIED ]

単体テスト、5,000件性能回帰、ブラウザE2Eで、主要な判断フローを確認した。

[ SAFETY BOUNDARY ]

外部API・サーバー保存・自動通報は行わない。最終判断は利用者に残す。
